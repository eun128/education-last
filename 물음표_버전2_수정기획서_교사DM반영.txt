[ 물음표 — 우리 학교 공부 도우미 플랫폼 버전 2 수정 기획서 ]
작성자: 김은아
수정일: 2026. 11. 27.
관련 주제: SDGs 4번 ‘양질의 교육’
대상 웹사이트: https://education-2-dist.vercel.app/

※ 이 문서는 기존 기획서에 역할 선택, 교사 비밀번호 입장, 교사와의 1:1 DM 질문 기능을 반영한 수정안입니다. 실제 구현이 완료되었다는 의미는 아닙니다. 현재 웹사이트의 구현 상태는 별도 확인이 필요합니다.

═══ 1. 한 줄 소개 ═══
모르는 문제를 사진이나 글로 편하게 질문하고, 게시판에서 친구들과 함께 배우거나 선생님에게 1:1 DM으로 질문하면서 이해한 내용을 우리 학교 공부 자료로 쌓아가는 익명 학습 플랫폼입니다.

═══ 2. 배경 및 필요성 ═══
학생들은 수업 중 모르는 내용이 있어도 친구들 앞에서 질문하기 창피하거나 부담스러워 그냥 넘어가곤 합니다. 이런 학습 공백이 쌓이면 수업을 따라가기 어려워지고 배움에 대한 자신감도 떨어질 수 있습니다.

기존 게시판은 여러 사람이 질문과 답변을 함께 보고 서로 도울 수 있다는 장점이 있습니다. 다만 공개된 공간에 질문하기 부담스럽거나, 특정 선생님에게 자신의 풀이를 자세히 확인받고 싶은 학생에게는 별도의 개인 질문 공간이 필요합니다. 따라서 게시판 질문·답변 기능을 유지하면서 교사와의 1:1 DM 질문창을 함께 제공합니다.

또한 ‘어디가 헷갈리는지 설명하기 어렵다’, ‘수식이나 그림을 글로 옮기기 번거롭다’, ‘뭘 모르는지도 모르겠다’는 학생에게는 사진 질문과 질문 작성 안내가 필요합니다. 질문 이후에도 답변 대기 상태와 이해 여부를 확인해 학습이 이어지도록 합니다.

사이트 첫 화면에서는 교사와 학생의 이용 경로를 나눕니다. 학생은 복잡한 가입 절차 없이 바로 이용하고, 교사는 지정된 비밀번호를 입력해야 교사 프로필과 답변 화면으로 들어갈 수 있도록 합니다.

═══ 3. 기존 이용 방식과 버전 2의 차이 ═══
기존 이용 방식은 게시판에 질문을 올리고 댓글 형태로 답변을 주고받는 흐름을 중심으로 합니다. 기존 기획서에 제안되어 있던 1:1 질문은 이번 수정안에서 교사와 대화하는 DM 형태로 구체화합니다.

버전 2에서는 다음을 개선합니다.
1) 사이트 최초 진입 화면에 ‘학생으로 시작하기’와 ‘교사로 시작하기’를 제공합니다.
2) 학생은 회원가입, 로그인, 비밀번호 입력 없이 바로 학생 화면으로 이동합니다.
3) 교사는 비밀번호 ‘12345’를 정확히 입력해야 교사 프로필과 교사 화면으로 이동합니다.
4) 기존 게시판 질문·답변 기능을 유지하면서 교사를 선택해 개인적으로 질문하는 1:1 DM을 추가합니다.
5) 글뿐 아니라 문제 사진과 자신의 풀이 사진도 게시판과 DM에 첨부합니다.
6) 질문 작성 도우미, 미답변 질문 관리, 해결 여부 확인으로 질문 이후의 학습을 돕습니다.
7) 공개 동의와 최종 미리보기를 거친 내용만 공부 자료집으로 공유합니다.

═══ 4. 이해관계자 분석 ═══
▸ 질문하는 학생 — 주요 사용자
불편함: 공개 질문이 부담스럽고, 문제나 풀이 과정을 글로 설명하기 어렵습니다. 가입 절차가 복잡하면 질문을 시작하기 전에 이용을 포기할 수 있습니다.
사용 목적: 학생 버튼으로 바로 입장해 게시판에 질문하거나, 원하는 선생님을 선택해 1:1로 질문합니다. 이해할 때까지 추가 설명을 받고, 질문 공개 여부를 직접 결정합니다.

▸ 답변하는 학생·선배 — 보조 사용자
불편함: 도움을 줄 질문을 찾기 어렵고 질문자가 어디까지 이해했는지 파악하기 어렵습니다.
사용 목적: 게시판의 과목별 미답변 질문에 답변하고 함께 복습합니다. 교사와 학생 사이의 비공개 DM에는 접근하지 않습니다.

▸ 교사 — 1:1 답변자 및 콘텐츠 품질 관리자
불편함: 학생이 어려워하는 부분을 파악하기 어렵고 공개 게시판의 질문과 개인 질문을 구분해 관리할 필요가 있습니다.
사용 목적: 교사 비밀번호 입력 후 교사 프로필로 입장해 자신에게 온 DM을 확인하고 답변합니다. 게시판의 미답변 질문과 ‘아직 어려워요’ 상태의 질문도 확인하고 설명을 보완합니다.

═══ 5. 첫 진입 화면과 서비스 공간 ═══
1) 역할 선택 화면
사이트에 처음 들어오면 메인 화면보다 먼저 ‘어떤 역할로 이용하시나요?’를 표시하고 다음 두 버튼을 제공합니다.
- 학생으로 시작하기
- 교사로 시작하기

‘학생으로 시작하기’를 누르면 추가 절차 없이 학생 메인 화면으로 이동합니다. 이름, 학번, 이메일, 비밀번호 등의 입력을 요구하지 않습니다.

‘교사로 시작하기’를 누르면 비밀번호 입력 화면을 표시합니다. 입력값이 ‘12345’와 정확히 일치할 때만 교사 프로필과 교사 메인 화면으로 이동합니다. 비밀번호 입력 중에는 문자를 가려 표시합니다. 입력하지 않거나 틀리면 입장시키지 않고 ‘비밀번호가 올바르지 않습니다. 다시 입력해 주세요.’라고 안내합니다. 역할 선택으로 돌아가는 버튼도 제공합니다.

선택한 역할과 교사 입장 상태는 현재 이용 세션 동안 유지합니다. ‘역할 변경’ 또는 교사 ‘나가기’를 누르면 교사 입장 상태를 해제하고 역할 선택 화면으로 돌아갑니다. 학생 화면에서 교사로 전환할 때도 비밀번호를 다시 입력해야 합니다.

2) 우리 반 공부 고민 게시판
기존처럼 학생들이 익명으로 질문과 공부 고민을 올리고, 학생·선배·교사가 답변하는 기본 공간입니다. 1:1 DM을 추가해도 게시판 작성과 답변 기능은 그대로 유지합니다.

3) 선생님께 1:1 질문하기
학생이 선생님 목록 또는 교사 프로필에서 ‘1:1 질문하기’를 눌러 해당 교사와의 비공개 DM 대화방을 엽니다. 학생은 익명으로 표시하고 교사는 이름과 담당 과목을 표시합니다. DM은 게시판과 별도 공간으로 제공합니다.

4) 우리 학교 공부 자료집
질문자와 답변자가 공개에 동의하고 최종 확인한 질문·답변을 공유합니다. 게시판의 글이나 1:1 대화가 자동으로 자료집에 공개되지는 않습니다.

5) 역할별 화면 구성
학생 화면: 게시판 / 선생님께 질문하기 / 내 대화 / 공부 자료집 / 내 활동
교사 화면: 교사 프로필 / 받은 1:1 질문 / 게시판 / 질문 검토 목록
공통: 현재 역할 표시 / 역할 변경

═══ 6. 주요 기능 설계 ═══
[기능 1: 역할 선택과 교사 비밀번호 입장]
학생은 역할 선택만으로 사이트를 이용합니다. 교사는 지정 비밀번호 ‘12345’를 입력한 경우에만 교사 프로필로 입장합니다. 학생 화면에서는 교사 전용 답변함, 프로필 수정, 교사 확인 처리 기능을 사용할 수 없습니다.

교사 전용 주소에 직접 접근하거나 새로고침해도 유효한 교사 입장 상태가 없으면 비밀번호 화면으로 이동하도록 합니다. 교사 메뉴를 숨기는 것과 별도로 교사 전용 데이터 조회·수정 요청에도 권한을 확인합니다.

이 비밀번호는 이번 버전에서 요청한 공통 입장 비밀번호이며, 실제 교사 신원을 확인하는 수단과는 구분합니다. 비밀번호를 안다는 이유만으로 ‘학교 인증 교사’라고 표시하지 않습니다. 여러 교사가 실제로 개인 대화를 운영할 때는 교사별 식별과 대화 접근 권한을 별도로 적용합니다.

[기능 2: 교사와의 1:1 DM 질문]
학생은 선생님 목록에서 이름, 담당 과목, 응답 가능 시간을 확인하고 ‘1:1 질문하기’를 누릅니다. 선택한 선생님과 이미 대화방이 있다면 기존 대화방을 열어 대화가 이어지도록 합니다.

대화방 상단에는 교사 이름과 담당 과목을 표시합니다. 중앙에는 이전 메시지를 시간순으로 보여주고, 학생과 교사의 말풍선 위치를 구분합니다. 하단에는 메시지 입력창, 사진 첨부 버튼, 전송 버튼을 배치합니다. 빈 메시지는 전송되지 않으며 사진만 첨부한 질문은 보낼 수 있습니다.

학생은 첫 질문 이후에도 같은 대화방에서 추가 질문을 보냅니다. 교사는 ‘받은 1:1 질문’에서 대화를 선택해 답변합니다. 대화 목록에는 상대 표시명, 최근 메시지, 최근 메시지 시각, 읽지 않은 메시지 수를 표시합니다. 읽지 않은 메시지 수는 해당 대화를 열어 확인하면 갱신합니다.

학생 화면에서는 ‘내 대화’에서 본인의 DM만 확인하고, 교사 화면에서는 해당 교사에게 온 DM만 확인합니다. 다른 학생이나 다른 교사의 대화는 볼 수 없습니다. 메시지와 첨부 사진은 기본 비공개이며 게시판에 자동 등록되지 않습니다.

학생에게는 대화방마다 구분 가능한 익명 표시명을 부여합니다. 회원가입 없이 이용하더라도 자신의 대화를 구분할 수 있도록 서버가 발급한 추측하기 어려운 익명 세션을 사용합니다. 표시명만으로 대화 접근 권한을 판단하지 않습니다. 같은 브라우저에서 재접속하면 유효한 익명 세션으로 이전 대화를 불러오며, 다른 기기나 브라우저 데이터 삭제 후에는 별도 복구 기능이 없는 한 이전 대화를 이어볼 수 없음을 내 대화 화면에 안내합니다.

메시지 전송 중에는 진행 상태를 표시하고, 실패하면 작성 내용과 첨부 파일을 유지한 채 재전송할 수 있게 합니다. 실제 사용자 간 이용 단계에서는 학생과 교사가 서로 다른 기기로 접속해도 메시지가 전달되고, 새 메시지가 대화 화면에 갱신되어야 합니다.

답변자의 응답 가능 시간을 안내하며 즉시 답변을 보장하지 않습니다. 각 질문은 ‘답변 대기 / 대화 중 / 해결됨’ 상태로 구분합니다. 대화방 안에서 새 질문을 시작할 때는 이전 질문과 해결 상태를 구분해 기록하고, 과거 대화도 계속 확인할 수 있도록 합니다.

[기능 3: 문제 촬영·사진 첨부 질문]
학생이 카메라로 문제를 촬영하거나 기기에 저장된 사진을 선택해 게시판 또는 1:1 DM에 첨부합니다. 수식, 도형, 지문, 자신이 작성한 풀이를 그대로 보여줄 수 있습니다.

사진은 필요한 부분만 자르고 모르는 부분에 동그라미나 밑줄을 표시할 수 있도록 합니다. ‘문제의 뜻을 모르겠어요’, ‘이 풀이 단계가 어려워요’, ‘제 풀이가 맞는지 봐주세요’ 중 하나를 선택하거나 자유롭게 설명합니다.

사진 미리보기에서는 이름·학번·얼굴 등이 포함되었는지 확인하고 해당 부분을 자르거나 가릴 수 있게 합니다. 카메라 사용을 허용하지 않아도 파일 선택이나 글 질문을 이용할 수 있습니다. 업로드 실패 시 작성한 글을 유지하고 재시도할 수 있게 합니다.

자동 문제 풀이는 기본 기능에 포함하지 않습니다. 사진 속 글자를 추출해 질문 작성을 돕는 기능은 추후 확장 대상으로 둡니다.

[기능 4: 질문 작성 도우미]
빈 입력창만 보여주는 대신 다음 순서로 짧게 안내합니다.
- 어떤 과목·단원인가요?
- 어떤 문제인가요? 사진을 올려도 좋아요.
- 어디까지 이해했고, 어느 부분에서 막혔나요?

‘어디가 어려운지도 모르겠어요’ 선택지를 제공하고 모든 안내 항목을 채우지 않아도 질문을 시작할 수 있게 합니다. 교사 DM에서는 선택한 교사의 담당 과목을 참고 정보로 표시하고 대화 도중에도 자유롭게 추가 설명을 보낼 수 있게 합니다.

[기능 5: 공부 고민 게시판과 가벼운 참여]
학생은 익명으로 질문을 올리고 친구와 선배, 교사는 답변을 남깁니다. ‘나도 궁금해요’ 버튼으로 새 글을 쓰지 않고도 같은 궁금증을 표현할 수 있습니다.

게시글에는 과목, 단원, 답변 수, 해결 상태를 표시합니다. 질문 작성 시 ‘게시판에 질문하기’와 ‘선생님께 1:1 질문하기’를 구분해 보여주고, 전송 전에 공개 범위와 수신 대상을 확인할 수 있게 합니다.

[기능 6: 미답변 질문 관리]
게시판에는 ‘답변을 기다려요’ 필터를 제공하고 오래 기다린 질문을 먼저 볼 수 있게 합니다. 교사의 받은 DM 목록에서도 미답변 질문과 읽지 않은 대화를 구분해 확인할 수 있게 합니다.

일정 시간 동안 답변이 없으면 질문자에게 다른 답변자에게 도움을 요청할지 선택하게 합니다. 1:1 대화나 첨부 사진은 다른 사람에게 자동 전달하지 않으며, 질문자가 공유할 내용과 대상을 확인한 뒤 요청하도록 합니다.

[기능 7: 해결 여부 확인과 추가 질문]
답변을 받은 질문자가 ‘해결됐어요’ 또는 ‘아직 어려워요’를 선택합니다. 답변이 달렸다는 이유만으로 자동 해결 처리하지 않습니다.

‘아직 어려워요’를 선택하면 ‘예시가 필요해요’, ‘더 쉬운 설명이 필요해요’, ‘이 부분을 다시 설명해 주세요’ 등의 문구로 추가 질문을 시작할 수 있습니다. 교사 DM에서는 같은 대화방에서 설명을 이어갑니다. 해결 후에도 이해가 부족하면 해당 질문의 상태를 다시 변경할 수 있습니다.

[기능 8: 답변 반응과 선생님 확인]
게시판의 ‘도움이 됐어요’는 학습에 도움이 된 정도를 표현하는 반응입니다. ‘보충이 필요해요’는 부드러운 피드백으로 유지하고 그 수는 답변자 본인에게만 보여줍니다.

실제로 교사가 내용을 검토한 답변에만 ‘선생님 확인 완료’를 표시합니다. 교사 비밀번호로 입장했다는 사실이나 반응 수만으로 게시판의 모든 답변을 확인 완료로 표시하지 않습니다. 내용이 수정되면 확인 표시를 해제하고 재검토하도록 합니다. 잘못된 설명이나 부적절한 내용은 신고할 수 있게 합니다.

[기능 9: 익명 공개 전환과 최종 미리보기]
교사와의 DM은 기본 비공개입니다. 질문자가 공개를 선택하지 않으면 그대로 유지합니다. 자료집에 공유하려면 답변자의 동의를 받고 질문자가 실제 게시될 내용을 최종 확인합니다.

대화 전체를 그대로 올리는 대신 핵심 질문과 답변을 정리하고 글과 사진에 포함된 개인정보를 확인합니다. 자동 가림을 도입하더라도 최종 미리보기에서 직접 수정할 수 있도록 합니다.

사진은 기본적으로 공개 대상에서 제외하고 필요한 사진만 별도로 선택해 확인합니다. 교재 전체 페이지를 불필요하게 공유하지 않도록 안내합니다. 개인정보가 남아 있거나 확인·저장에 실패하면 비공개 상태를 유지합니다.

[기능 10: 학교 공부 자료집과 복습 저장]
공개가 완료된 질문·답변을 과목·단원별로 분류하고 검색할 수 있게 합니다. ‘나중에 복습’으로 저장한 자료는 내 활동에서 모아볼 수 있습니다. 자료에는 선생님 확인 여부를 함께 표시합니다.

[기능 11: 내 활동과 알림]
학생은 내 게시판 질문, 내 DM, 답변을 기다리는 질문, 아직 어려운 질문, 저장한 자료를 확인합니다. 교사는 받은 DM과 추가 설명 요청을 확인합니다.

새 메시지가 오면 ‘내 대화’ 또는 ‘받은 1:1 질문’에 읽지 않은 메시지 수를 표시합니다. 공개 알림에는 비공개 대화의 본문이나 사진을 노출하지 않습니다. 사이트 밖 알림은 후속 기능으로 두고, 기본 단계에서는 사이트 안에서 새 메시지를 안내합니다.

═══ 7. 대표 이용 흐름 ═══
[상황 A: 학생이 선생님께 DM으로 질문하기]
단계 1 — 사이트에 접속해 ‘학생으로 시작하기’를 누릅니다. 가입이나 비밀번호 입력 없이 학생 메인 화면으로 이동합니다.
단계 2 — ‘선생님께 질문하기’를 누르고 원하는 교사를 선택합니다.
단계 3 — 교사 이름과 담당 과목을 확인한 뒤 ‘1:1 질문하기’를 눌러 대화방을 엽니다.
단계 4 — 문제와 자신의 풀이를 사진으로 첨부하거나 글로 질문을 작성합니다. 사진 속 이름 등을 확인하고 가립니다.
단계 5 — 수신 교사와 비공개 대화임을 확인하고 전송합니다.
단계 6 — 교사의 답변을 확인하고 이해되지 않는 부분을 같은 대화방에서 추가로 질문합니다.
단계 7 — 이해했다면 ‘해결됐어요’를 누릅니다. 아직 어렵다면 추가 설명을 요청합니다.
단계 8 — 원할 때만 참여자 동의와 최종 미리보기를 거쳐 자료집에 공유합니다.

[상황 B: 교사가 받은 질문에 답변하기]
단계 1 — 첫 화면에서 ‘교사로 시작하기’를 누릅니다.
단계 2 — 비밀번호 ‘12345’를 입력합니다. 일치하면 교사 프로필과 교사 메인 화면으로 이동합니다.
단계 3 — ‘받은 1:1 질문’에서 읽지 않은 메시지나 답변 대기 질문을 확인합니다.
단계 4 — 대화방을 열어 학생의 질문과 사진을 확인하고 답변합니다.
단계 5 — 추가 설명 요청이 오면 같은 대화방에서 대화를 이어갑니다.
단계 6 — 이용을 마치면 ‘나가기’로 교사 입장 상태를 해제합니다.

[상황 C: 학생이 기존 게시판을 이용하기]
단계 1 — ‘학생으로 시작하기’로 바로 입장합니다.
단계 2 — 게시판에서 과목·단원과 질문 내용을 작성하고 글이나 사진을 등록합니다.
단계 3 — 친구·선배·교사의 답변을 확인하고 반응 또는 추가 질문을 남깁니다.
단계 4 — 이해 여부를 표시하고 필요하면 복습 자료로 저장합니다.

═══ 8. 데이터와 메시지 처리 단계 ═══
1) 입장 및 역할 부여
학생 선택 시 익명 이용 세션을 발급하고 학생 화면을 엽니다. 교사 선택 시 비밀번호를 검사하고 성공한 경우에만 교사 권한이 있는 세션을 발급합니다. 실제 사용자 간 운영에서는 비밀번호 검사와 권한 부여를 서버에서 처리하며 비밀번호를 화면 코드에 넣어 비교하는 방식만으로 보호하지 않습니다.

2) 교사 및 대화방 선택
학생의 익명 세션과 수신 교사를 연결해 대화방을 생성하거나 기존 방을 불러옵니다. 교사 프로필이 여러 개라면 공통 비밀번호만으로 타 교사의 대화에 접근하지 않도록 교사별 계정과 권한 구분을 마련합니다. 단일 교사 시연에서는 지정된 시연용 교사 프로필 하나로 입장하도록 합니다.

3) 질문 입력과 사진 확인
글, 사진, 과목·단원, 선택한 질문 유형을 입력합니다. 사진의 필요한 부분을 자르고 개인정보를 가린 뒤 수신 대상과 공개 범위를 확인합니다.

4) 저장 및 전달
대화방 참여 권한, 파일 형식·크기를 확인한 뒤 질문과 첨부 파일을 서버에 저장하고 상대 화면에 전달합니다. 위치 등 불필요한 사진 메타데이터는 저장 전에 제거합니다. 공개 게시판 데이터와 DM 데이터를 구분하고, 사진 접근에도 대화방과 같은 권한을 적용합니다.

5) 수신 확인 및 이해 확인
새 메시지와 읽지 않은 메시지 수를 갱신하고 추가 설명 요청과 해결 상태를 기록합니다. 전송 실패 시 메시지를 보낸 것으로 표시하지 않으며 초안을 유지합니다.

6) 선택적 공개
참여자 동의, 공개할 글·사진 선택, 익명 정리 및 최종 확인을 거친 내용만 자료집에 등록합니다. 원본 DM을 공개 주소로 노출하지 않습니다.

7) 오류 및 종료 처리
비밀번호 오류 시 교사 입장을 차단하고 재입력 또는 역할 선택을 제공합니다. 카메라 권한 거부 시 파일 선택·글 질문을 제공합니다. 교사 나가기 시 권한을 해제하고, 이후 교사 데이터에 다시 접근하려면 비밀번호 입력이 필요하도록 합니다.

═══ 9. 구현 우선순위 ═══
[최우선: 이번 수정 요청]
- 최초 진입 시 학생·교사 역할 선택 화면
- 학생 선택 시 가입·로그인 없이 즉시 입장
- 교사 선택 시 비밀번호 ‘12345’ 검사와 교사 프로필 진입
- 비밀번호 오류 안내, 역할 변경, 교사 나가기
- 교사 선택 → DM 대화방 생성 → 질문 전송 → 교사 답변 → 추가 질문
- 학생의 내 대화, 교사의 받은 1:1 질문, 읽지 않은 메시지 표시
- 기존 게시판 질문·답변 기능 유지

[함께 유지할 버전 2 핵심 개선]
- 문제 촬영·사진 첨부, 사진 자르기·표시·개인정보 가리기
- 질문 작성 도우미와 미답변 질문 필터
- ‘해결됐어요 / 아직 어려워요’ 상태와 추가 질문
- 글·사진을 포함한 공개 전 최종 미리보기

[실제 사용자 간 운영에 필요한 기반]
- 서버 저장과 서로 다른 기기 사이의 메시지 전달
- 회원가입 없는 학생 이용을 위한 익명 세션 관리
- 서버에서 교사 비밀번호 검사 및 역할·대화 참여 권한 확인
- DM과 첨부 사진의 비공개 접근 제어
- 여러 교사 운영 시 교사별 계정·신원 확인과 대화 권한 구분
- 신고·차단, 질문·대화·첨부 사진 삭제, 자료 공개 철회 처리
- 삭제·공개 철회 시 자료집의 첨부 사진도 함께 처리하는 규칙

[후속 개선]
- 선생님 확인 기능과 검토 목록
- 자료집 단원 필터, 복습 저장, 내 활동 모아보기
- 답변 도우미 연결과 알림 설정
- 사진 속 글자를 추출해 질문 작성을 돕는 기능

공통 비밀번호 ‘12345’와 단일 교사 프로필은 이번 시연의 입장 방식으로 적용합니다. 실제 학생의 비공개 대화를 여러 교사가 운영하는 단계에서는 교사별 인증을 갖춰야 합니다. 학생은 그 단계에서도 가입·로그인 입력 없이 입장하는 흐름을 유지하고 익명 세션으로 본인 대화 접근을 구분합니다.

브라우저 내부 저장만 사용하는 시연이라면 ‘이 기기 안에서만 저장되는 체험용 대화’임을 표시합니다. 실제 전송·인증이 구현된 부분과 체험으로 제공하는 부분을 구분하며, 교사에게 실제 전달되지 않는 메시지를 전달 완료로 표시하지 않습니다.

═══ 10. 검증 계획 ═══
[역할 선택과 입장]
- 첫 방문에서 학생·교사 선택 화면이 먼저 표시되는가?
- 학생 버튼을 누르면 입력 절차 없이 학생 화면으로 이동하는가?
- 교사 비밀번호가 ‘12345’일 때만 교사 프로필로 이동하는가?
- 빈 값이나 잘못된 비밀번호 입력 시 교사 화면에 들어가지 못하는가?
- 학생이 교사 전용 주소에 직접 접근하거나 새로고침해도 교사 권한을 얻지 못하는가?
- 역할 변경 또는 교사 나가기 이후 교사 기능을 다시 사용하려면 비밀번호가 필요한가?

[교사 DM과 게시판]
- 학생이 원하는 교사를 선택해 대화방을 열고 글·사진을 보낼 수 있는가?
- 교사는 받은 질문을 확인하고 같은 대화방에서 답변할 수 있는가?
- 실제 전송 단계에서는 학생·교사가 서로 다른 기기에서도 메시지를 주고받을 수 있는가?
- 추가 질문, 재접속 후 대화 불러오기, 읽지 않은 메시지 표시가 동작하는가?
- 메시지 전송 실패 시 작성 내용이 남아 있고 재전송할 수 있는가?
- 다른 학생·교사가 DM 본문이나 첨부 사진에 접근하지 못하는가?
- DM을 이용해도 기존 게시판의 질문 등록과 답변이 정상적으로 동작하는가?

[사용성 확인]
- 공개 게시판 질문과 교사 DM 중 원하는 방식을 쉽게 선택하는가?
- 글로만 질문할 때보다 사진 질문을 시작하기 쉬웠는가?
- 질문이 누구에게 보이는지 정확히 이해했는가?
- 답변을 받은 뒤 해결 여부와 추가 설명 요청 방법을 찾을 수 있었는가?
- 공개 전 미리보기에서 사진 속 개인정보를 확인할 수 있었는가?

운영 단계에서는 질문 등록에 걸린 시간, 게시판·DM 이용 비율, 미답변 질문 비율, 첫 답변까지 걸린 시간, 해결 표시 비율, 추가 설명 후 해결된 비율을 확인합니다. 초기 사용 결과를 바탕으로 개선 목표를 정하며 검증 전부터 학습 성적 향상을 단정하지 않습니다.

═══ 11. 기대 효과 ═══
- 학생이 가입 절차 없이 질문을 시작할 수 있어 이용 진입 부담을 줄입니다.
- 공개 질문이 부담스러운 학생도 선생님에게 DM으로 편하게 질문할 수 있습니다.
- 게시판에서 함께 배우는 방식과 교사에게 개별 도움을 받는 방식을 상황에 맞게 선택합니다.
- 사진 질문과 추가 대화로 학생이 막힌 부분을 구체적으로 설명할 수 있습니다.
- 교사는 받은 질문과 미답변 대화를 모아보고 학생의 이해 여부를 확인할 수 있습니다.
- 공개에 동의한 질문과 답변이 학교 맞춤형 학습 자료로 축적됩니다.
- 학생이 질문하고 도움받을 기회를 넓혀 SDGs 4 ‘양질의 교육’ 목표에 기여하고자 합니다.
